# Blog Lua — 3 páginas

Projeto Next.js com três páginas funcionando:

- `/` — Início
- `/sobre` — Sobre
- `/fotos` — Fotos

## Como executar

Abra o terminal na pasta do projeto e execute:

```bash
npm install
npm run dev
```

Depois abra http://localhost:3000

## Build de produção

```bash
npm run build
npm start
```
